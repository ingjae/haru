# Haru 사용법

## 레일과 상세 화면

기본은 왼쪽 24px 레일, 09:00–21:00 타임라인입니다. 레일을 클릭하면 상세 화면이 펼쳐집니다. 다른 곳을 클릭하거나 **레일 접기**를 누르면 접히며, 설정·편집 중에는 열린 상태를 유지합니다. hover만으로는 확장되지 않습니다.

빨간 선은 현재 시간을 가리킵니다. 축소 상태의 삼각형은 레일 밖에 겹쳐 표시되고 클릭을 아래 앱으로 통과시킵니다. 일정 제목은 축소 블록 안에 작은 세로 글씨로 표시할 수 있습니다.

## 일정 만들기·수정

- 빈 시간대를 클릭하면 15분 단위로 시작 시간을 잡고 1시간짜리 새 일정 폼을 엽니다. **＋**로도 생성할 수 있습니다.
- 제목·시작/종료·설명·장소·알림을 입력하고 **만들기**를 누릅니다.
- **종일 일정**은 날짜 범위로 지정합니다. 화면의 종료 날짜는 마지막 날을 포함합니다.
- 반복 생성은 매일·매주·매월·매년을 지원합니다. 기존 반복 일정 수정·삭제는 선택한 회차에만 적용합니다.
- 일정 블록을 클릭해 내용을 수정하거나 회의 링크를 엽니다. 삭제는 **삭제 → 삭제 확인** 두 단계입니다.
- 읽기 전용 캘린더의 일정은 수정·삭제할 수 없습니다.

상단에서 날짜와 캘린더를 선택합니다. macOS 메뉴바 타임라인은 오늘 일정을 유지하고, 다른 날을 보다가 레일을 접으면 오늘로 돌아갑니다. 범위 밖 일정은 상세 화면 위쪽의 별도 버튼으로 접근합니다.

## Google 할일

**＋ → 할일**에서 제목·날짜·설명을 입력합니다. 할일 목록은 상단 선택기로 바꿀 수 있습니다. [추가 권한과 Tasks API 설정](GOOGLE_SETUP.md#캘린더-목록과-google-할일)

- **일정 / 할일** 버튼으로 두 종류를 각각 켜고 끌 수 있습니다. 표시 설정은 저장됩니다.
- 선택한 날짜의 할일은 위쪽 칩과 아래 목록에 표시됩니다. 날짜 없는 할일은 아래 목록에서 볼 수 있습니다.
- 체크박스로 완료·취소하며, 항목을 클릭해 수정·삭제합니다.
- 완료 항목은 **기기의 오늘 날짜에 완료한 것만 오늘 화면에 표시**합니다. 예정 날짜가 과거여도 오늘 완료했다면 포함합니다. 이전 완료·완료 시각 없는 항목은 숨깁니다.
- **시간 지정(main, 미출시)**을 켜면 할일 시작·종료와 저장할 캘린더를 선택할 수 있습니다. 빈 시간에서 열었다면 선택한 시간을 초기값으로 사용합니다.
- 시간 지정 할일은 타임라인·메뉴바에 시간 블록으로 표시하며 클릭하면 같은 할일을 수정합니다. 완료 상태·제목·설명을 시간 블록에도 반영합니다.
- 시간 지정을 끄면 시간 블록만 제거합니다. 할일 삭제는 연결된 시간 블록도 함께 삭제합니다. 기존 시간 블록의 캘린더 이동은 아직 지원하지 않습니다.
- Google Tasks API가 자체 시간 필드를 제공하지 않아, Haru는 **Google Calendar의 일반 일정 블록**으로 시간을 함께 저장합니다. Google Tasks 웹의 자체 시간 필드를 설정하는 기능은 아닙니다. Google 웹에서 한쪽만 수정한 변경을 양방향으로 자동 맞추지는 않습니다.
- 실제 Google 계정의 시간 블록 생성·복구 전체 흐름은 아직 미검증입니다. 현재 MacBook 샘플에서 생성·표시·완료·시간 해제를 확인했습니다.

## 표시와 창 배치

**⚙ 설정 → 표시**에서 레일 배경, 축소 상태 세로 제목, 전체 투명도를 조절합니다. 투명도 0%가 가장 선명합니다. 배경 옵션은 축소 레일에 적용하며 확장 패널 배경은 별도 옵션이 없습니다.

**타임라인 시간**은 시작·종료를 30분 단위로 설정합니다. 기본값 09:00–21:00이며 종료는 24:00까지 가능합니다.

| 배치 | 동작 |
| --- | --- |
| 왼쪽·오른쪽 | 24px 레일, 클릭 시 상세 화면 |
| 위쪽 | 넓은 패널 형태 |
| 일반 창 | 독립 일정 창 |
| 메뉴바 아래 · macOS | 메뉴 항목 클릭으로 패널 열기 |
| 메뉴바 타임라인 · macOS | 시스템 메뉴바 안의 가로 일정 막대 |

메뉴바 타임라인은 120–1200px 또는 **최대한 넓게(자동)** 중 선택하고 15초마다 갱신합니다. 자동 폭은 화면과 메뉴 항목 위치를 바탕으로 여유 공간을 추정합니다. 다른 메뉴 항목과 노치 때문에 화면 전체를 채우는 것은 보장하지 않습니다.

macOS의 **화면 공간 확보**는 손쉬운 사용 권한으로 활성 앱의 일반 창이 레일을 침범할 때 위치·폭을 조정합니다. macOS 작업 영역 자체를 예약하지 않으며 전체 화면·최소화·Finder·다른 모니터 창은 제외합니다. 앱의 최소 크기·타일링 방식에 따라 겹칠 수 있고, 확장 패널은 다른 창을 밀지 않습니다.

Linux에서는 [데스크톱 환경별 제한](LINUX.md)을 확인하세요.

## 알림·회의

**현재 main(미출시)**의 알림은 **⚙ 설정 → 일정 알림 사용**에서 켜고 끕니다. 끄면 예약된 타이머와 현재 말풍선도 취소됩니다. Calendar popup 알림과 캘린더 목록에서 읽은 기본 알림을 따르며, 시간 지정 할일은 시작 시각에 알립니다. 캘린더 기본 알림을 읽으려면 목록 읽기 권한이 필요합니다.

**레일 옆 말풍선 표시**와 **없음 / 살짝 나오기 / 통통 튀어나오기** 애니메이션을 선택할 수 있습니다. 말풍선은 별도 작은 창으로 레일 옆에 나타나며 레일을 자동 확장하거나 포커스를 가져오지 않습니다. 8초 뒤 사라지고, 클릭하면 해당 일정·할일을 엽니다. **미리보기**는 설정 창을 닫고 축소 레일 옆의 예시 말풍선을 20초 동안 보여 줍니다. OS의 동작 줄이기를 따릅니다.

시스템 알림은 OS의 Haru 알림 권한을 따릅니다. 앱 종료·잠자기 중 전달은 지원하지 않으며 실제 Google 일정에서 OS 알림까지의 전체 흐름은 별도 확인이 필요합니다.

화상회의 링크는 Google 회의 필드와 설명·장소에 있는 Meet·Zoom·Teams 주소를 인식합니다. 상단 캘린더 아이콘이나 메뉴바 우클릭 메뉴로 Google Calendar 웹을 기본 브라우저에서 열 수 있습니다.

## 지원 범위와 검증

실기기 확인은 현재 개발용 Apple Silicon MacBook 한 대에 한정됩니다. 다른 Mac·Intel Mac·Linux 실기기의 PASS를 의미하지 않습니다. 버전별 패키지 실행 결과는 [README](../README.md#버전별-검증)에 표시합니다.

현재 개발 버전은 Google Calendar 전체 기능과 동등하지 않습니다. 참석자 초대·Meet 생성, 전체 반복 편집, 캘린더 생성·공유는 미구현입니다.

| 확인한 것 | 추가 확인이 필요한 것 |
| --- | --- |
| Mac arm64 패키지 실행·설정 버전 표시 | 서명·공증, Intel Mac 배포 |
| Mac 실제 Google 로그인·일정·할일 조회 | 실제 계정 생성·수정·삭제·회의·알림 전체 흐름 |
| Mac 클릭 확장·바깥 클릭 접기 | 모든 스냅·전체 화면·여러 모니터 조합 |
| 샘플 생성·수정·삭제·할일 완료, 현재 main 테스트 48개 | 장시간 실행·잠자기 이후 복구 |
| Ubuntu 24.04 Xvfb에서 AppImage 추출본의 샘플 실행 | 실제 GNOME/Wayland 화면 배치·Linux Google OAuth |
| DMG 및 AppImage 체크섬 | Linux 데스크톱별 키링·트레이 호환성 |

샘플 모드는 실제 Google 인증을 읽지 않습니다. 샘플 변경사항은 재시작하면 초기화됩니다. [미디어와 검증 화면 안내](MEDIA.md)

### 주·월 보기 (main 개발 버전)

상단 일·주·월 버튼으로 보기를 선택합니다. 주·월은 최대 1180px로 확대되며 화면 안에 맞춥니다. 월은 월요일 기준 6주 달력, 주는 7일 목록입니다. 날짜 숫자는 일 보기, ＋는 해당 날짜 일정·할일 생성, 일정 제목은 상세 편집으로 연결됩니다. 이전·다음은 선택한 보기 단위로 이동합니다. 날짜 안의 일정이 많으면 해당 칸을 스크롤합니다. v0.0.3 배포 파일에는 아직 포함되지 않았습니다.
