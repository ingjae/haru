## 2. 제품 요청

**사용자**

> 여기에서 맥북 용도의 구글 캘린더 기반으로 오늘의 스케쥴을 타임 라인으로 시각화 하고 클릭하여 화상회의 참가나 해당 일정에 대한 수정, 알림이 가능한 앱을 만들고 싶어

**어시스턴트**

오늘의 Google 캘린더 일정을 타임라인으로 보고 클릭하여 회의 참가·수정·알림 설정을 하는 앱을 만들기로 했다. 플랫폼 선호를 질문하고, 답변 전에는 샘플 데이터를 사용하는 웹 UI 개발을 시작했다.

**질문**

선택지: 웹 앱 / macOS 데스크톱 앱.

**사용자 답변**

## 3. 화면 위치와 지속 표시

**사용자**

> 스크린의 맨 왼쪽/오른쪽/위/ 메뉴바 등의 위치에 시각화도 항상 되는 기능을 가져야 해

**어시스턴트**

Electron 기반 독립 macOS 앱으로 전환했다. 화면 왼쪽·오른쪽·위 배치, 항상 위 표시, 메뉴바를 통한 위치 설정을 구현했다. Google 로그인은 시스템 브라우저와 localhost 콜백 및 PKCE로 진행하도록 만들었다. 회의 링크는 시스템 브라우저로 열고, 알림은 Electron Notification을 사용한다.

## 4. 위젯 동작 명확화

**사용자**

> 열지 않아도 그냥 보이도록

**사용자**

> 사실상 항상 보여야해 클릭해서는 여러 설정을 할수 있지만 위젯같은 형태야

**사용자**

> 지금 이거를 실행시키는 컴퓨터는 맥북인데

**어시스턴트**

클릭해서 여는 패널이 아니라 항상 보이는 프레임 없는 위젯으로 변경했다. 메뉴바 아래 배치도 계속 표시하게 했다. 사용자 컴퓨터는 맥북이지만 코드를 작성하는 클라우드 실행 환경은 Linux임을 설명했다. 사용자 맥북에서 앱을 직접 실행한 상태는 아니라고 명확히 안내했다.

## 5. 최종 위젯 요구사항

**사용자**

> 예를 들어 맨왼쪽에 기본 시간 오전 9시 부터 오후 9시 까지의 시간대가 쭉 늘어져 있고 색상별로 보이고 , 현재 시간에 따른 위치가 가 표시 되고 마우스오버되면 조금더 확장되서 보이는 그런 게 필요해
>
> 목젃은 전체 맥락상의 남은 시간 이나 회의 분포를 한눈에 보고 , 추가로 바로 오늘 일정에 접근해서 수정이나 화상 회의 참가하고, 일정이 다가오면 말풍선이 생기고 거기에 내용이 잠깐보였다가 사라지는거야

**어시스턴트**

기본 위치를 왼쪽으로 변경했다. 88px 좁은 레일에 09–21시 일정 색상 블록과 현재 시간 선을 표시한다. 마우스를 올리면 420px로 확장하고, 벗어나면 축소한다. 편집 중에는 축소하지 않는다. 일정 알림은 위젯을 확장하여 8초 동안 말풍선을 표시하고 사라지게 구현했다. 현재 시간은 기기 시간대를 사용한다.

## 6. 로컬 이전

**사용자**

> 로컬로 옮겨오거나 환경을 맥환경으로 변경 할수는 없나

**어시스턴트**

이 Linux 클라우드를 macOS로 변경하거나 사용자 맥북으로 직접 복사할 수는 없다고 설명했다. 로컬 이전용 `haru-source.zip`을 만들었다. Node.js 20 이상을 설치하고 압축을 풀어 다음 명령으로 실행하도록 안내했다.

```sh
cd ~/Downloads/haru
npm ci
npm start
```

Google 연결 전에는 샘플 일정이 표시된다. 실제 연결에는 Google Cloud의 데스크톱 OAuth 클라이언트 JSON이 필요하다. 맥북 Codex에서 폴더를 열고 실제 macOS 환경에서 개발을 이어갈 수 있다고 안내했다.
