**어시스턴트**

```sh
cd ~/Downloads/haru
npm ci
npm start
```

## 2026-10-14 완료 표시·그룹 선택 (main 미출시)

주·월 할일이 항상 빈 네모였던 표시를 상태별 SVG 체크 네모와 취소선으로 수정. 일 타임라인·상단 칩도 동일한 상태 아이콘 사용. 상단 그룹 버튼에서 캘린더·할일 목록 여러 개 또는 모두 해제 가능, 로컬 preferences에 저장. 기존 드롭다운은 새 항목 저장 대상으로 사용. 각 조회 항목에 원래 캘린더/목록을 붙여 상세 편집·삭제·완료 API가 해당 그룹으로 전달되도록 수정. 같은 ID의 다른 그룹 알림/할일 연결도 구분. 시간 블록은 할일 그룹 선택을 따르며 캘린더 블록이 숨겨진 경우에도 선택한 할일의 시간은 표시.
