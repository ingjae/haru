# Haru v0.0.4 릴리즈 초안

상태: 준비 중. 태그·공개 릴리즈는 아직 생성하지 않았습니다. 현재 다운로드는 v0.0.3입니다.

## 주요 변경

- 일·주·월 보기와 화면 크기에 맞춰 확대되는 주간 목록·월간 달력.
- 여러 일정 그룹을 함께 선택하고 그룹별 색상 지정. Google 원본 색상은 변경하지 않습니다.
- 오늘 완료한 할일의 체크 네모·취소선 표시 수정.
- 할일 시간 지정과 연결된 Calendar 시간 블록.
- 짧은 일정 제목·한글 글꼴 보완, 알림 스위치와 별도 말풍선 애니메이션.
- 메인 화면에서 저장 대상·표시 옵션을 분리. 화면/캘린더/알림 설정 탭, 접히는 추가 편집 옵션.

## 설치 파일 준비

- macOS Apple Silicon: `Haru-0.0.4-arm64.dmg`
- Ubuntu 24.04 x86_64: `Haru-0.0.4-x86_64.AppImage`
- 파일별 SHA-256 체크섬 포함 예정.

## 확인된 범위

- 자동 테스트 57개 통과.
- 현재 Apple Silicon MacBook 샘플 앱: 정리된 메인, 설정 탭/버전 표시, 저장 캘린더가 있는 일정 폼에서 생성 확인.
- 이전 main에서 실제 Google 계정 캘린더·할일 목록/다중 그룹 조회와 완료 표시 확인.
