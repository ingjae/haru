개인정보처리방침

이 문서는 ingjae가 배포하는 Haru 오픈 소스 데스크톱 앱의 Google 사용자 데이터 처리 방식을 설명합니다. OAuth 동의 화면의 앱 이름은 현재 watt-app일 수 있습니다.

1. 접근하는 정보와 목적

  • Google Calendar의 일정 제목, 시간, 설명, 장소, 회의 링크, 알림 및 일정 식별자를 읽고 사용자가 요청한 일정 생성·수정·삭제에 사용합니다.
  • 추가 권한을 연결하면 캘린더 목록의 이름·색상·접근 권한과 Google Tasks 목록·할일 제목·메모·날짜·완료 상태를 읽고, 사용자가 요청한 할일 관리를 수행합니다.
  • 시간을 지정한 할일은 Google Tasks 항목과 연결되는 일반 Google Calendar 시간 블록을 만들며 연결 식별자를 해당 일정의 비공개 확장 속성에 저장합니다.

2. 저장하는 곳과 보관

Google 인증 토큰과 OAuth 클라이언트 정보는 운영체제의 암호화 저장 기능을 통해 암호화된 파일로 기기에 저장합니다. 지원되는 암호화 저장소를 사용할 수 없으면 Google 연결을 허용하지 않습니다. 표시할 캘린더·목록 식별자, 색상, 화면·알림 설정 등 환경설정은 기기의 앱 데이터 폴더에 저장됩니다.

조회한 일정·할일과 알림 예약 정보는 앱 실행 중 메모리에서 처리합니다. 원본 일정·할일과 사용자가 요청한 변경 내용은 Google 서비스에 저장됩니다. Haru는 별도의 운영자 서버에 Google 일정·할일 사본을 전송하거나 보관하는 기능을 두지 않습니다.

3. 전송·공유 및 알림

앱은 기기에서 Google 인증·Calendar·Tasks API에 HTTPS로 직접 통신합니다. 알림을 켜면 일정 제목과 시간이 운영체제 알림에 표시될 수 있습니다. 사용자가 회의 링크나 Google Calendar 열기를 선택하면 해당 주소가 브라우저에서 열립니다. 이때 해당 서비스의 정책이 적용됩니다.

현재 배포 코드에는 Google 사용자 데이터를 광고, 판매, 데이터 브로커 제공 또는 범용 AI 모델 학습에 사용하는 기능이 없습니다. 서비스의 동작을 위한 Google API 사용을 제외하고 Haru 개발자에게 일정·할일 내용을 자동 전송하는 분석 기능은 포함하지 않습니다.

4. 연결 해제·삭제

앱의 연결 해제는 해당 기기에 저장된 Google 인증 파일을 삭제하고 예약된 알림을 지웁니다. Google의 기존 일정·할일은 삭제하지 않습니다. Google 계정의 서드 파티 연결 관리에서 앱의 접근을 취소할 수 있습니다. 환경설정을 완전히 지우려면 앱을 종료한 뒤 운영체제의 Haru 앱 데이터 폴더를 삭제합니다.

5. Google 데이터 사용 제한

Haru의 Google API 사용자 데이터 사용 및 다른 앱으로의 전송은 Google API Services User Data Policy와 Limited Use 요구사항을 따르는 것을 원칙으로 합니다.

6. 안내 웹사이트·문의

이 안내 웹사이트는 Google 로그인·일정 데이터를 받지 않는 정적 페이지입니다. 호스팅 제공자인 GitHub의 처리는 GitHub 개인정보 안내를 참고하세요. 앱의 데이터 처리 문의는 Haru GitHub Issues로 접수할 수 있습니다. 공개 문의에는 인증 파일·토큰·비밀번호·비공개 일정 내용을 첨부하지 마세요.
